# Numeric-only diagnostic replay fixtures

These four CSVs contain only the nine documented scalar columns emitted by the
experimental shadow collector: guest monotonic time, receiver time, cumulative
coded/generated bytes, outcome/status, sample delta/coverage and observed rate.
They contain no packet payloads, keys, account data, addresses or session IDs.
Guest clock values are retained to reproduce the exact sampler arithmetic.

Source: the two extension-shadow cases in the original four-mode QEMU pilot,
not production traffic. **Both application transfers failed with short echo EOF.**
A complete numeric trace does not make those runs successful. See
[results and limitations](../../../docs/experiments/arrival-evidence-results.md).
`client.csv` represents uplink feedback; `server.csv` represents downlink feedback.
The offline benchmark uses a synthetic identity and does not reconstruct the
original session lifecycle or ciphertext.

Run the equal-input driver with this directory as `--input-root`. Measurements
can vary by host; semantic checksums and Collector replay rows should agree.
Full VM images, private archives, raw application/network logs and manifests
with local machine paths are intentionally excluded.
