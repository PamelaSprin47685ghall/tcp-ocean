# A/B:main 与 sq3(未发送上限 2 帧 + TCP_NOTSENT_LOWAT)

条件:run.sh 20 ms 单向、200 Mbit、5% 丢包、4 路径、10 s;交替运行。合入规则:只有"只好不坏"才合入。
A = main(feec499 / f42f12c),B = sq3(6e735b0 / b438ef8 = main + e700412)。第二轮用 SKIP_IPERF=1。

| 运行 | ping p99 | 负载下 ping p99 | bulk up | bulk down 1 / 2 | 备注 |
|---|---|---|---|---|---|
| A1 | 47.9 | 121.5 | 151.8 | 134.2 / 133.6 | iperf 128/134/134/134/121 |
| B1 | 42.0 | 140.6 | 134.4 | 134.8 / 135.0 | iperf 后两项被 255 s 虚拟机暂停打断,作废 |
| A2 | 42.0 | 104.5 | 151.5 | (作废) / 134.8 | down 1 遇到 clock_jumps=4(暂停),srtt 一度 1.9 s |
| B2 | 42.7 | 174.1 | 140.0 | 134.3 / 135.2 | clock_jumps=0 |
| A3 | 54.7 | 109.9 | 149.6 | 133.6 / 133.9 | clock_jumps=0 |
| B3 | 61.8 | 179.9 | 146.3 | 118.8 / 130.1 | clock_jumps=0 |

## 结论:不合入

| 指标 | A(main)3 次 | B(sq3)3 次 |
|---|---|---|
| bulk up | 151.8 / 151.5 / 149.6 | 134.4 / 140.0 / 146.3(三次都更低) |
| 负载下 ping p99 | 121.5 / 104.5 / 109.9 | 140.6 / 174.1 / 179.9(三次都更差) |
| 空闲 ping p99 | 47.9 / 42.0 / 54.7 | 42.0 / 42.7 / 61.8(无差别) |
| bulk down | 133.6–134.8 | 118.8–135.2 |

两项三次全部变差,不满足"只会更好"(ONLY-1…5)。浅队列本应降低负载下延迟,结果反而升高:
单独把未发送上限设为 2 帧、不配合就绪集与会话级交互信用(16.3.3–16.3.4),
交互帧并没有因此更早上线,而上行吞吐被压低。sq3 分支保留,不合入。
