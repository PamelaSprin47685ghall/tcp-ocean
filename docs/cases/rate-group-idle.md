# 真空闲不能继承上一个突发的满管计数

基线：`2bc29689b5fa1a77df57648d7d4d2d10c9c12a99`。

## 机制

`RateGroup.Service` 有两条采样路径。有交付时，低于一个 BDP 的轮次会清
`fullCount`；完全无交付时，原代码保留计数。已有 idle 单测每毫秒仍交付
100 B，覆盖了低速流量，没有覆盖真正的零流量。

因此，一个启动中的组可以在前一突发积累两次满管无增长记录，完全空闲后，
在下一突发的第一个满管样本就退出 startup。新旧突发的证据被拼在一起。
这与当前规则中“空闲后重新观察三次满管无增长”不一致。

修复仅在**本轮零交付、当前零在途、且本轮零发送**时清 `fullCount`。
判定使用更新前的 `sampleSent`，新数据和修复副本都计入发送。
无交付但仍有在途的中断保留原行为，避免每个丢失轮次都把计数清零，
导致 startup 无法结束。带宽滤波、阶段、增益、窗口和发送速率上界保持原值。

## 可复核的输入与状态

以 200 Mbit/s、40 ms RTT 为例，一轮交付 1 MB，满管判定仍为在途至少 1 MB。
以下测试直接向真实控制器提供完整轮次的发送、交付和在途计数。
它验证状态机，不模拟网络吞吐。

| 轮次 | 输入 | 原逻辑的 `fullCount` / 阶段 | 修复后的 `fullCount` / 阶段 |
| --- | --- | --- | --- |
| 1 | 满管，建立带宽样本 | 0 / startup | 0 / startup |
| 2 | 满管，带宽未增长 | 1 / startup | 1 / startup |
| 3 | 满管，带宽未增长 | 2 / startup | 2 / startup |
| 4–7 | 零发送、零交付、零在途 | 2 / startup | 0 / startup |
| 8 | 恢复满管，带宽未增长 | 3 / drain | 1 / startup |
| 9 | 满管，带宽未增长 | 已退出 startup | 2 / startup |
| 10 | 满管，带宽未增长 | 已退出 startup | 3 / drain |

上述满管轮次不依赖 `TryTake` 拒绝，保留 `2bc2968` 的修复。

新增 [RateGroupTests.fs](../../tests/Tbt.Tests/RateGroupTests.fs) 覆盖：

- 20/200 Mbit/s、40 ms，以及 32/256 Mbit/s、400 ms，成员数为 1/4/8/64。
  真空闲后重新计三轮，带宽估计不被清空。
- 无交付但仍有在途的中断：保留带宽与已有满管证据，不改修复节奏。
- 8 路的 16/36 Mbit/s 残留和 64 路的 64/99 Mbit/s 残留：恢复时立即保留
  `2.885` 启动增益，并能接受同方向更大的带宽样本，没有先等一轮 `1×` 探测。
- 20 上 / 200 下、80 上 / 8 下两组不对称速率：一侧的空闲、退出 startup
  和带宽增长均不改另一侧的估计。

这些数值是测试输入，不是产品速率常数。现有 no-SACK、blackout、RepairWait
测试的断言不变。

## 诊断

组日志保留原有字段，并加入 `full_rounds`、`app_rounds`、`pacing_mbit`、
`send_mbit`、`sample_mbit` 和 `copy_mbit`。`phase` 明确区分 startup、drain
和 probe。零交付轮次报告零 goodput，不再在日志里沿用上一个有交付轮次的速率。

`bw_mbit` 是保留的带宽估计；`goodput_mbit` 是本轮唯一交付速率；
`copy_mbit` 是另列的副本估计；`sample_mbit` 是受发送速率约束后的候选样本。
`send_mbit` 记录最近一轮实际发送计数的速率，与控制器保留的前一有效轮发送上界分开。

## 验收边界

这处缺陷不能直接解释默认配置下 64 路上行的 93–121 Mbit/s 散度。
基线的 `UPLINK_PACE=0` 不启用 `SessionCarrier` 内的上行 `RateGroup`；
默认上行需要从内核路径、发送调度和修复情况继续取证。

单测证明的是真空闲后的状态转移。8 路快/慢残留、64 路、20/200 0%/5%
与非对称线路的实际吞吐仍需官方 A/B：按段排除主机停顿及所属会话的日志 gap，
每侧每段至少两个有效种子样本，8 路 down1 按残留类分别比较，并同时覆盖
bulk、iperf 单流、iperf 并行和 pingbulk 准时率。没有这些样本就不作性能合入结论。
